Four-song album audit

Read Four_Song_Album_Audit.pdf or .md first. Evidence is measured / estimated / interpretive. No direct listening was available. Originals are excluded and untouched.

Reproduce: place four WAVs in upload/ alongside analysis/ and output/. Run python analysis/analyze.py, python analysis/peak_details.py, python analysis/finish_features.py, python analysis/build_report.py. Dependencies: Python, numpy, scipy, matplotlib, reportlab and system ffmpeg/ffprobe. See analysis/versions.json.

Charts use physical units or explicitly labeled normalized algorithm scores. No quality rating or song-five prescription is included.
