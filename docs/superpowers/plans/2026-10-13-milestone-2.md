## Global Constraints

- Protected baseline is commit `a387bb2`, `ALGORITHM_VERSION = "m1-v3"`, charts T01–T10.
- Accepted audio remains 16-bit or 24-bit integer PCM WAV. The blob `blobs/{sha256}` stays byte-identical. Lyric routes do not open it.
- Evidence classes are `measured`, `estimated`, `textual`, `interpretive`, `unknown`, and `not_applicable`. Status values stay `not_run`, `ready`, `not_available`, and `failed`. A status is never stored in `evidence_class`.
- Tempo, pitch-class, structure, and recurrence stay estimated. Do not infer instrumentation, vocal character, mood, or audible defects. Do not invent sung timestamps.
- Lyric revisions never enter the analysis cache key. `measure.py`, the T01–T10 builders, `png.py`, and the worker stay untouched.
- No ZIP export, narrative provider, album comparison, forced alignment, or new DSP library.
- Frontend types come from regenerating `frontend/src/api/types.ts`. Do not hand-edit that file.
- From `backend/`: `uv run ruff check . && uv run pytest -q`. From `frontend/`: `pnpm typecheck && pnpm test && pnpm build`.

## Review Focus

These are the inputs most likely to be shown as sung timing, a fresh measurement, or a musical conclusion. Each one has a test in the matrix below.

1. An SRT cue whose end is less than its start is stored and kept off every time axis.
2. A second save that still carries the old document revision does not overwrite the newer text.
3. A lyric upload or timing edit leaves `analysis/{sha256}/m1-v3/T02.json` and `evidence.json` byte-identical and inserts no job.
4. An interpretive sentence appears only for a written repeat or a stored level difference, and its citations are ids in the same chart.
5. A recording with no usable lyric interval still returns a ready L03 built from the stored T02 series.

## Corrections applied

- **L03** reads the stored T02 series and, when a lyric interval is usable, places that interval on the same time axis and reports the mean of the stored samples inside it. With no usable interval, L03 still shows the stored energy series and the stored equal-duration windows.
- **L05** shows measured, estimated, and textual findings, plus two conditional interpretive templates. Each template cites evidence ids. Vocal, emotional, melodic, sectional, and instrumental principles stay explicit insufficient rows. No narrative route is added.
- Lyric routes are scoped to a project-asset membership. One current document per membership is a partial unique index. Writes compare `expected_revision` inside `BEGIN IMMEDIATE`.
- Technical evidence files are only read. The combined evidence object is a separate response. Lyric chart documents carry `lyric_revision` and are not stored beside `m1-v3`.
- The test matrix covers reversed and malformed SRT, stale revisions, project isolation, cache identity, L03 overlays, and L05 citations.

### File identity and deletion

The stored path is `data_root / "lyrics" / sha256`. The uploaded filename is `original_name` and is never joined to a path. The same sha256 is one row in `lyric_files` and one file. A second project-asset upload of those bytes inserts another `lyric_uploads` row and reuses the file.

`DELETE /lyrics` for one membership, in one transaction:

1. Delete that membership's `lyric_documents` (segments, segment revisions, and validation follow by cascade).
2. Delete that membership's `lyric_uploads`.
3. For each sha256 that no longer has an upload row, delete the `lyric_files` row and the file.

Annotations for the membership remain. A deleted segment sets `annotations.segment_id` to null. The WAV blob and `analysis/{sha256}/m1-v3/` are not deleted.

A new upload marks the previous document `is_current = 0` and leaves its file in place while its upload row remains. There is no history HTTP route in this milestone.

Write the file before the database transaction. If the process stops after the rename and before commit, the unreferenced file matches its hash and a later upload of the same bytes reuses it. Do not add a sweeper. Mark that ceiling in `backend/app/lyrics.py`:

```python
# ponytail: orphan lyrics/{sha256} if the process dies after rename and before commit. Same bytes reuse the file.
```

There is no project-delete route today. Do not add one. A later project delete has to remove that project's lyric rows and then delete lyric files with no remaining upload.

### Parsing

Accept `.txt`, `.md`, and `.srt` by the final suffix, case-insensitive. Other suffixes return 415 `unsupported_lyrics`. Stream with the existing spool helper, capped at 1 MiB. Decode as UTF-8. A decode failure returns 422 `not_utf8` and deletes the temp file. Store the original bytes unchanged.

TXT and MD: one segment per non-empty line, ordinal from 0, times null, origin `unplaced`. Markdown marks stay in `text`.

SRT: split cues on blank lines. A cue keeps its index in `source_cue` and its body, including internal newlines, in `text`. The timestamp line must match `HH:MM:SS,mmm --> HH:MM:SS,mmm`.

| Condition | Stored times | Origin | Validation code |
|---|---|---|---|
| Timestamp line does not match | both null | `unplaced` | `malformed_time` |
| Times match and `end <= start` | the supplied numbers | `subtitle_supplied` | `reversed_time` |
| `start < end`, but `start < -0.001` or `end > duration_s + 0.001` | the supplied numbers | `subtitle_supplied` | `out_of_range` |
| Two in-range, ordered cues overlap | the supplied numbers | `subtitle_supplied` | `overlap` on each |
| Cue body is empty or whitespace | as otherwise parsed | as otherwise parsed | `empty_cue` |
| `.srt` file contains no cue | no segments | — | `unparsed` on the document, `segment_id` null |

An empty TXT creates a document with zero segments and no validation row. Overlap does not remove a cue from the usable set. Reversed, malformed, and out-of-range cues are not usable and are not overlap partners.

```python
def usable(start_s: float | None, end_s: float | None, duration_s: float) -> bool:
    if start_s is None or end_s is None or not start_s < end_s:
        return False
    return start_s >= -0.001 and end_s <= duration_s + 0.001
```

The first `lyric_segment_revisions` row copies the parsed segment at document revision 1.

Word count, used for L02 and density: on each line, remove one leading `#` run and then strip surrounding `*` and `_`. Count whitespace-separated tokens that contain a letter or number.

Repetition key: `casefold`, drop characters that are not alphanumeric or whitespace, collapse whitespace. Segments whose key is empty do not repeat. A key seen on two or more segments is one repetition record. The id is `ly:repeat:` plus the first 16 hex characters of the SHA-256 of that key.

### Verification transitions

`artist_verified` is true only when `timing_origin` is `manual_verified`. The API does not accept an origin or a verified flag on the segment PUT. A PUT that changes times must send a usable interval or clear both times. Reversed and out-of-range numbers stay only on the preserved SRT ingest. The `manual_edit` check constraint requires `end_s > start_s`, so a text edit must not relabel a reversed cue as a manual interval.

| Action | Result |
|---|---|
| PUT replaces times with a usable interval | `manual_edit`, `artist_verified` false |
| PUT clears both times | `unplaced`, null times, `artist_verified` false |
| PUT sends reversed, partial, or out-of-range times | 422 `interval_not_usable`; no write |
| PUT changes text only, and the stored interval is usable | `manual_edit`, times unchanged, `artist_verified` false |
| PUT changes text only, and the stored interval is not usable | times and origin stay as ingested (`subtitle_supplied` or `unplaced`); `artist_verified` false |
| PUT changes the note only | origin, times, and verified flag stay; revision still increments |
| verify `true` on `unplaced`, `subtitle_supplied`, or `manual_edit` with a usable interval | `manual_verified`, `artist_verified` true |
| verify `true` when the interval is not usable | 422 `interval_not_usable`; no write |
| verify `true` when the origin is already `manual_verified` | 200, revision unchanged |
| verify `false` from `manual_verified` | `manual_edit` when times remain usable; `unplaced` when they do not |
| verify `false` when the segment is not `manual_verified` | 200, revision unchanged |

Clearing verification does not restore `subtitle_supplied`. The artist had marked the line, so a still-usable interval stays `manual_edit`.

### Stale writes

Every lyric mutation and every annotation mutation for a segment runs in `BEGIN IMMEDIATE`.

1. Read `lyric_documents.revision` for the current document of this membership.
2. If it differs from `expected_revision`, roll back and return 409 `stale_revision` with `current_revision`.
3. Apply one segment change, append one segment-revision row, and set `revision = revision + 1`.
4. Commit.

The segment id does not change. A PUT or verify whose segment is not on the current document of this membership returns 404 `not_current`. Historical documents stay readable only in SQLite.

Extend `AppError` with an optional `extra` dict. The handler copies those keys onto the existing `{"error", "message"}` body. Existing errors gain no new keys.

```json
{"error": "stale_revision", "message": "The lyric document changed.", "current_revision": 4}
```

Persisted records are copied from `evidence.json` when its `algorithm_version` is `m1-v3`. The file's `kind` becomes `evidence_class`. `persisted` is true. `cites` is empty. Lyric fields are null. The file is not rewritten. A missing file, or any other algorithm version, contributes no technical records and sets `analysis_version` null.

Derived technical ids are views over stored chart JSON. `persisted` is false. They are omitted when that chart file is missing, not `ready`, or not `method_version == "m1-v3"`.

| Id | Class | Source |
|---|---|---|
| `ev:t02:rms-1s` | `measured` | T02 line named `1 s RMS` |
| `ev:t02:short-term-lufs` | `measured` | T02 line named `3 s short-term LUFS` |
| `ev:t02:windows` | `measured` | T02 bar labels and the window caveat |
| `ev:t08:provisional-change` | `estimated` | T08 markers whose label is `provisional_change` |
| `ev:t09:similarity` | `estimated` | T09 heatmap and its melody caveat |

Lyric ids, all `persisted` false, all carrying the current `lyric_document_id` and `lyric_revision`:

| Id | Class | When |
|---|---|---|
| `ly:{segment_id}` | `textual` | every current segment; `interval_s` is set only when `usable` |
| `ly:repeat:{hex16}` | `textual` | a normalized key on at least two segments; `cites` lists those `ly:{segment_id}` values |
| `ly:density:{segment_id}` | `textual` | word count divided by `end_s - start_s`, usable segments only |
| `ly:level:{segment_id}` | `measured` | `10*log10` of the mean of `10^(dBFS/10)` for stored `1 s RMS` samples with `start_s <= x < end_s` |
| `ly:lufs:{segment_id}` | `measured` | the same mean over stored `3 s short-term LUFS` samples |

`ly:level` and `ly:lufs` cite `ly:{segment_id}` and the matching `ev:t02:*` id. `ly:level` uses method `t02-stored-mean-square-v1`: invert each stored dBFS value with `10^(dB/10)`, average those powers with equal weight per stored frame, then apply `10*log10`. T02 already drops a short trailing frame, and a frame at the m1-v3 power floor stays at that floor. `ly:lufs` stays an arithmetic mean of stored LUFS samples, method `t02-stored-sample-mean-v1`, because LUFS is not mean-square power. A usable interval with no sample inside it produces neither id.

Sample membership is half-open, so a sample that lands on a shared boundary belongs to the later interval.

Changing a lyric time changes `lyric_revision` and the values of the derived lyric ids. It does not change a persisted id, a stored chart file, or `ev:t02:*`. Clients discard a lyric chart whose `lyric_revision` differs from the current document. Charts are not written under `analysis/`, so an old lyric chart cannot remain there as the current reference.

### L01

Depends on stored T02 `1 s RMS`, stored T08 `provisional_change` markers, and usable lyric regions.

- T02 not usable: status `not_available`, reason from T02 or `Stored T02 energy is not m1-v3.`
- T02 usable: copy that line. Class `measured`, evidence id `ev:t02:rms-1s`. Axis x `Time (s)`.
- T08 usable: copy its provisional markers into `review_markers` with the stored caveat `Not a verified verse, chorus, or section boundary.`
- T08 absent: the chart stays ready and the caveat says `Provisional change markers are unavailable.`
- Usable segments become `regions`. Untimed, reversed, malformed, and out-of-range segments are counts in `summary` and are not regions.
- No usable segment: still ready, `regions` empty, summary `Lyric timing: unavailable`.
- Clicking a region button seeks `start_s`. The playhead follows the time axis.
- L01 does not compute interval means.

### L02

Depends only on the current document.

- No document: `not_available`, reason `No lyric document is attached.`
- Every segment, including unusable ones, is a word-count bar. Axis x `Line`, so there is no playhead and no seek. Class `textual`.
- A words-per-second point exists only for a usable segment. Unusable ordinals are null on that line.
- Caveat, exact: `Word counts are written tokens, not vocal delivery or breaths.`
- An empty document is `ready` with empty series and that caveat.

### L03

Depends on stored T02 and, when present, usable lyric intervals. It does not call DSP.

- T02 not usable: `not_available`.
- Copy the `1 s RMS` and `3 s short-term LUFS` lines when those lines exist. Same `x` and `y` as the file. Axis x `Time (s)`.
- No usable lyric interval: also copy the T02 bars with their stored labels. Summary `Lyric timing: unavailable. Showing stored full-mix energy only.` Chart class `measured` when every copied series is measured. Caveat includes the stored window sentence: these are analysis windows, not verses, choruses, or emotional sections.
- One or more usable intervals: do not copy the equal-duration bars. Add a `regions` entry per usable segment. Summary numbers for `ly:level` and `ly:lufs` come from `canonical_evidence`, not from a second mean. When the RMS mean is absent, the summary says `No stored 1 s RMS sample falls inside this written interval.`
- For each consecutive usable pair that does not overlap, if both have an RMS mean, add a summary item `Stored 1 s RMS means differ by {delta:.2f} dB.` Delta is the later mean minus the earlier mean.
- Timed-mode caveat, exact: `Interval values are means of stored full-mix samples. They are not singing intensity, vocal energy, or emotion.`
- Chart class is `unknown` when regions and measured lines are both present, with the combined-class caveat.
- Seek and playhead behave as on a time axis. A region button seeks `start_s`.

### L04

Depends on stored T09 and current repetition records.

- Copy the T09 heatmap and its caveats when T09 is usable. Class `estimated`, evidence id `ev:t09:similarity`. A bright cell is not a matching melody or hook.
- Repetition records are `rows` of kind `finding`, class `textual`. They do not use the heatmap axes. Repeats do not need timing.
- T09 absent and a document present: heatmap null, rows kept, caveat `The recurrence chart is unavailable.` Status `ready`.
- T09 present and no document: heatmap kept, summary `No lyric document. Text repetition is unavailable.`
- Neither: `not_available`.

### L05

Depends on the canonical bundle for this membership. No model call and no new prose outside the templates below.

Findings, kind `finding`, one row per included record, value and caveat copied:

- every persisted `evidence.json` record
- every `ly:{segment_id}`, `ly:repeat:*`, `ly:density:*`, `ly:level:*`, and `ly:lufs:*` record
- `ev:t02:rms-1s` and `ev:t02:short-term-lufs` when present, so a level principle can cite them

`ev:t08:provisional-change` and `ev:t09:similarity` are cited by insufficient rows. They are not restated as section or melody findings.

Interpretive rows, kind `principle`, class `interpretive`. Only these two templates may be emitted, and only when the condition holds.

**Written repetition.** Condition: at least one `ly:repeat:{hex16}` record. One principle per such record.

- Id: `ly:principle:written-repetition:{hex16}`
- Cites: `[that repetition id]`
- Value, exact: `A written line occurs {n} times. Transferable mechanism: a later lyric can bring a phrase back. Do not copy this recording's words. The repeat is not a melody or hook.`

**Level contrast.** Condition: among consecutive non-overlapping usable intervals that both have `ly:level`, the largest absolute difference is at least `1.0` dB. One principle, for that pair.

- Id: `ly:principle:level-contrast`
- Cites: the two `ly:level:{segment_id}` ids, in start-time order
- Value, exact: `The written intervals {a0:.3f}–{a1:.3f} s and {b0:.3f}–{b1:.3f} s differ by {delta:.2f} dB in the mean of stored 1 s RMS values. Transferable mechanism: a later lyric can change where the full mix already changes level. This is not singing intensity, vocal performance, or emotion.`

`LEVEL_CONTRAST_DB = 1.0` lives next to the template. It is a reporting gate in `lyrics-v1`, not a loudness-perception model.

Insufficient rows are always considered. A code is present as a principle or as an insufficient row, never both, and never neither for the six fixed refusals. The six fixed reasons are always insufficient:

| Code | Reason |
|---|---|
| `tempo` | `No transferable tempo principle. An onset candidate is not a beat grid, meter, or groove.` |
| `melody` | `No melody or hook principle. Spectral similarity is not melodic identity.` |
| `section` | `No section principle. A spectral change point is not a verified verse or chorus.` |
| `vocal` | `No vocal-performance principle. This milestone does not estimate singing, alignment, or delivery.` |
| `emotion` | `No emotion principle. Full-mix level is not mood.` |
| `instrumentation` | `No instrumentation principle. Spectral shape is not an instrument identity.` |

`tempo.cites` is `["ev:pulse_candidate_bpm"]` when that persisted record exists, otherwise `[]`. `melody.cites` is `["ev:t09:similarity"]` when that view exists, otherwise `[]`. `section.cites` is `["ev:t08:provisional-change"]` when that view exists, otherwise `[]`. The other three cite nothing.

`written_repetition`, when refused: `No written-repetition principle. No normalized line occurs more than once.`

`level_contrast`, when refused, uses the first matching reason:

| Condition | Reason |
|---|---|
| T02 RMS view absent | `No level-contrast principle. Stored T02 energy is unavailable.` |
| Fewer than two intervals with an RMS mean | `No level-contrast principle. Fewer than two written intervals contain a stored 1 s RMS sample.` |
| Those intervals only overlap | `No level-contrast principle. The written intervals overlap, so their stored levels are not compared.` |
| Largest absolute difference under 1.0 dB | `No level-contrast principle. The largest stored 1 s RMS mean difference is {delta:.2f} dB, under the 1.00 dB lyrics-v1 gate.` |

Status is `ready` when `analysis_version` is `m1-v3` or a current lyric document exists. Otherwise `not_available`, reason `No technical evidence and no lyric document.` A ready L05 with only refusals is a valid result. The chart class follows the classes present on `rows`. Insufficient rows do not enter that set.

Every principle `cites` entry must be the `evidence_id` of a finding row in the same document. The builder drops a principle rather than emitting a citation it cannot resolve, and the matching insufficient row is emitted instead. In practice the two templates cite records the same function just added.

### Ingest and source preservation

- Empty SRT: document, zero segments, validation `unparsed`, 201.
- Empty TXT: document, zero segments, no validation row.
- TXT and MD lines: origin `unplaced`, null times, `usable` false.
- MD heading `## Keep *this*`: stored text unchanged; word count 2.
- SRT overlap: both cues keep their times, both get `overlap`, both stay `usable` when they are inside the file.
- SRT `00:00:02,000 --> 00:00:01,000`: stored `start_s` 2 and `end_s` 1, code `reversed_time`, origin `subtitle_supplied`, `usable` false, `artist_verified` false.
- SRT timestamp `not a time`: null times, `malformed_time`, origin `unplaced`, cue text kept.
- Cue ending after `duration_s`: times stored, `out_of_range`, `usable` false.
- `GET .../lyrics/source` body equals the uploaded bytes. A later text PUT leaves that body unchanged.

### Revisions, isolation, cache

- Time PUT keeps the segment id, sets `manual_edit`, sets `artist_verified` false, increments `revision`, and appends a segment-revision row.
- Text PUT on a reversed cue keeps `start_s` 2, `end_s` 1, and origin `subtitle_supplied`.
- A fixture T02 line produces `ly:level` equal to the stored sample inside the cue. The T02 file bytes are unchanged.
- PUT with `expected_revision` one behind the current revision returns 409 `current_revision`, and the segment text is the newer text.
- Verify `true` without a usable interval returns 422 and leaves the origin unchanged. Verify `true` on a usable `subtitle_supplied` cue is the only path to `manual_verified` in that test.
- Verify `false` from `manual_verified` returns `manual_edit` and `artist_verified` false.
- Note-only PUT keeps the origin.
- The same WAV attached to project A and project B: a lyric document on A is `no_lyrics` on B. A's segment id returns `not_current` on B.
- Two memberships uploading the same SRT bytes create one file under `lyrics/{sha256}`. Deleting A's lyrics leaves the file. Deleting B's lyrics removes the file. Both WAV blobs remain.
- After upload, a time edit, and a verify: the asset sha256, `metrics.json`, `T02.json`, and `evidence.json` are byte-identical, and the jobs count is unchanged.
- `POST /api/projects/{id}/narratives` and `POST /api/projects/{id}/exports` are 404.
